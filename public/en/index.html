QUESTIONS ABOUT THE TOOL

FAQ

01What does the tool check+

JSON-LD syntax, Schema.org types, key properties, absolute URLs, and the main page signals.

02Can I check a page that has no markup yet+

Yes. The tool builds a basic JSON-LD from the data it finds on the site.

03Does markup guarantee a rich result+

No. Correct markup helps a search engine understand the page, but the decision to show a rich result belongs to the search engine.

04Where do I put the generated JSON-LD+

Inside the page HEAD, or through your platform’s own field. On Tilda that is the extra HTML code in page settings.
